AccessLens

IAM Access Review Assistant

A safe learning project that reviews fictional identity and entitlement data, identifies common access risks, and prepares a manager-friendly review package.

Back to portfolio Download resume View source repository

What it demonstrates

A controlled access-review workflow

The project accepts fictional employee and entitlement records, applies transparent review rules, and produces clear findings for a human reviewer. It was created with AI coding assistance as a portfolio exercise and is separate from Rahul's employer work.

  1. Review the identity.Check status, manager, worker type, and sample entitlement history.
  2. Flag common risks.Highlight stale access, privileged access, lifecycle concerns, and conflicting permissions.
  3. Prepare the evidence.Create a structured summary and a draft manager email for review.
  4. Keep a person in control.The project cannot approve, remove, or change access.
