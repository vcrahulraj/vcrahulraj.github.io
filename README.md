# Rahul Raj — GitHub Portfolio

A fast, accessible static portfolio for an IAM and OT security analyst transitioning toward AI security and Generative AI engineering.

The site leads with:

- downloadable PDF and Word resume files;
- enterprise IAM and OT security experience;
- measurable, AI-assisted workflow automation;
- certifications, skills, and education; and
- two secure AI portfolio prototypes built with synthetic data, placed after the professional resume content;
- dedicated in-portfolio detail pages for both projects, so visitors are not sent to unpublished repositories;
- explicit boundaries between professional production work and independent portfolio prototypes.

## View locally

No build step or package installation is required.

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## Publish with GitHub Pages

Publish these files from the root of the public repository `vcrahulraj.github.io`. GitHub Pages will serve the site at:

`https://vcrahulraj.github.io/`

The `.nojekyll` file keeps GitHub Pages in static-file mode. Project and profile links are configured in `config.js`.

## Privacy and claim boundaries

- No client names, client data, internal documents, secrets, or employer source code are included.
- Workplace applications are described as AI-assisted development, not autonomous AI systems.
- AccessLens and the OT Security Alert Triage Agent are independent portfolio prototypes that use synthetic data.
- Portfolio projects do not connect to production IAM or OT systems and do not perform access changes or remediation.
